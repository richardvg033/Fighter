# Street Fighters — Player 1 vs Player 2

Een speelbare retro-vechtgame met twee personages geïnspireerd op de geüploade foto. Werkt direct in een browser zonder installatie.

## Spelen
Open `index.html` in je browser.

- Player 1: A/D bewegen, W springen, F slaan, G schoppen, H speciale aanval.
- Player 2: pijltjes links/rechts bewegen, omhoog springen, K slaan, L schoppen, O speciale aanval.

## Online publiceren met GitHub Pages
1. Maak op github.com een nieuwe **public** repository, bijvoorbeeld `street-fighters`.
2. Upload alle drie de bestanden uit deze map naar de hoofdmap van de repository.
3. Ga naar **Settings → Pages**, kies **Deploy from a branch**, selecteer `main` en `/ (root)` en sla op.
4. Na publicatie staat het spel op `https://JOUW-GEBRUIKERSNAAM.github.io/street-fighters/`.

De sprites zijn eenvoudige, met code getekende pixelpersonages; de arena gebruikt de gegenereerde pixelart.
