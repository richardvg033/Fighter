# Burger Rush — 50 Levels

Open `index.html` in a browser or host it with GitHub Pages.

This package includes 12 procedural terrain texture assets to provide a >10 MB asset bundle. The current browser game is a 2.5D canvas game; these textures are **not yet wired into the renderer**. The package size is not a measure of stability or 3D quality. For a real 3D version, replace the renderer with WebGL/Three.js and integrate optimized textures and character models.
